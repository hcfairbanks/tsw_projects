☢ Nuke DB

          power-user wipe (dev mode only)
        

        

          Wipes every user table except the curated seeds
          (countries, weather_presets, timetable_actions) so you
          can re-extract from scratch. Schema stays intact, autoincrement counters reset, and the
          file is VACUUMed so it actually shrinks. Requires typing
          nuke to confirm.
        

        

          
          
        

      

    

  


  
  

    

      
☢ Wipe the entire user catalog?

      
Every imported route, timetable, formation, train class, coordinate set, pak catalog
        entry — gone. This cannot be undone.

      
The following lookup tables will be kept (schema-seeded, not
        user-imported):

      
countries · weather_presets · timetable_actions

Getting Started Guide

Learn how to use the TSW HUD PROJECT to track your train journeys.

1

Extract Timetable from Images (OCR)

+

Use OCR to automatically extract timetable data from Train Sim World screenshots. You need to capture 8 or more images in a specific order.

Step 1: Capture Screenshots in TSW

In Train Sim World, capture these screenshots in order. Name them so they sort alphabetically (e.g., 1.png, 2.png, ... or use any names that sort correctly).

Image 1: Route Name

The route name from the service selection screen.

Example: Route name "Boston Sprinter"

Image 2: Service Name

The service header showing the full service name, start time, and duration.

Example: "MBTA Providence #815 (Boston - Providence)"

Image 3: Start Time

The start time value (HH:MM format).

Example: Start time "14:28"

Image 4: Duration

The service duration (HH:MM format).

Example: Duration "01:06"

Image 5: Tonnage

The train tonnage value from the level info bar.

Example: Tonnage "461.9"

Image 6: Car Count

The number of cars in the consist.

Example: Car count "6"

Image 7: Train Length

The train length in meters from the level info bar.

Example: Train length "148.7"

Images 8+: Timetable Pages

Screenshot each page of the timetable showing the stops, actions, and times. Capture as many pages as needed to cover the full timetable.

Example: Timetable page 1 - WAIT FOR SERVICE, stops, and times

Example: Timetable page 2 - continuation of stops

Step 2: Upload Images

  1. Go to the Timetables page or a Train detail page
  2. In the "Extract from Images" section, click or drag your screenshots into the upload area
  3. Make sure files are named so they sort in the correct order (1.png, 2.png, ... or alphabetically)
  4. The system will automatically process the images using OCR

Step 3: Review and Edit Extracted Data

  1. The route will be auto-matched and locations will populate as dropdowns
  2. Start time, duration, tonnage, car count, and train length will appear in the Level Info bar
  3. Review the extracted timetable entries in the table
  4. Click on any cell to edit if the OCR made mistakes
  5. Check that times are in HH:MM:SS format (e.g., 14:28:00)

Step 4: Complete the Timetable

  1. Enter or verify the Service Name
  2. Confirm the Route was correctly matched (or select one manually)
  3. Select at least one Train for this service
  4. Click "Create Timetable" to save
Important: The first location and first platform are not included in the in-game timetable screenshots and will need to be added manually.

Create Timetable Manually

+

Build a timetable from scratch by entering each stop manually.

Step 1: Start a New Timetable

  1. Go to the Timetables page
  2. Click the "+ Create New Timetable" button

Step 2: Enter Basic Information

  1. Enter the Service Name (e.g., "1C84 London Paddington to Penzance")
  2. Select the Route from the dropdown
  3. Select one or more Trains that can run this service

Step 3: Add Timetable Entries

Click "+ Add Entry" to add stops. For each entry:

  • Action: Select the type (WAIT FOR SERVICE, STOP AT LOCATION, LOAD PASSENGERS, etc.)
  • Location: Enter the station name
  • Platform: Enter the platform number if applicable
  • Time 1: Arrival time (HH:MM:SS format)
  • Time 2: Departure time (HH:MM:SS format)

Use the "Quick Add Common Entries" buttons to quickly add preset actions.

Step 4: Save the Timetable

Click "Create Timetable" when all entries are added.

Tip: You can always edit the timetable later by clicking on it in the timetables list.

Import Timetable from JSON

+

Import previously exported timetables or share timetables with others.

Importing a Timetable

  1. Go to the Timetables page
  2. In the "Import Timetable" section, click or drag a JSON file into the upload area
  3. The system will validate and import the timetable automatically
  4. You'll be redirected to the timetable view on success

Exporting a Timetable

  1. Open any timetable from the list
  2. Click the "Export JSON" button
  3. Save the JSON file to share or backup
Tip: JSON exports include all timetable data including coordinates, making them perfect for backups or sharing complete routes.

Record Timetable Coordinates

+

Record GPS coordinates for your timetable by running the route in Train Sim World while connected to the HUD Project.

Step 1: Open the Record Map

  1. Go to the Record Map page
  2. Select your Route from the dropdown
  3. Select the Train
  4. Select the Timetable you want to record

Step 2: Start Recording

  1. Start Train Sim World and load your service
  2. Click the "Start" button on the Record Map page
  3. Begin driving your route - coordinates will be recorded automatically
  4. The map will show your path in real-time

Step 3: Save Station Positions

As you arrive at each station:

  1. Select the station from the "Select Station" dropdown
  2. Click "Save Position" to record the coordinates
  3. The station will be marked with a green marker on the map

Step 4: Complete Recording

  1. When finished, click "Save" to process and save all data
  2. The recording will be processed and saved to the database
  3. Click "Reset" to clear and start fresh if needed
Recording Modes:
- Automatic: Recording auto-stops after 2 minutes of no movement
- Manual: Recording continues until you click Save
Tip: Use the "Pause" button if you need to take a break during recording. Resume when ready to continue.

Automatically Record Timetable Coordinates

+

Automatically record coordinates for your timetable entries while the AI drives the route for you. This explanation sounds more complicated than it is - a video tutorial will be added soon.

Step 1: In Game Setup

  1. Start Train Sim World
  2. Select your route
  3. Select your train
  4. Take a screenshot of the service name
  5. Start the timetable
  6. Do not touch any train controls
  7. Navigate to the schedule screen
  8. Take screenshots of the schedule (multiple if needed)

Step 2: In the App

  1. Start the server
  2. Select or create your route
  3. Select or create your train
  4. Upload your screenshots to the Timetables page
Important: The order of screenshots matters! They need to be in chronological order. If your screenshots have timestamps and you followed the flow above, you will be fine.

Step 3: Complete Timetable Data

  1. Go to Route Map to get the first location name and platform number
  2. Add the location name and platform number to the timetable
  3. Review and confirm the data - the "Service Name" often has OCR errors, but timetable data is usually accurate
  4. Click "Create Timetable"

Step 4: Start Auto Recording

  1. Go to the Recording page
  2. Select your route, train, and timetable
  3. Click "Record"

Step 5: Enable AI Driver (In Game)

  1. Use God Mode to access the console commands
  2. Enable the "Relinquish Service" command from the God Mode menu
  3. Sit in the copilot's seat
  4. Come back when automatic recording is complete

God Mode menu showing the "Relinquish Service" option

How Stop Detection Works:
- Each stop (including the first) must be recorded stopped for a minimum of 30 seconds to be identified as a stop
- If the train doesn't move for around 5 minutes (usually at the last stop), the server will automatically stop recording, identify all stops based on timing, and save everything to the database
Benefit: This method lets you enjoy all the data that comes from a full route recording without having to sit through the entire journey!

Using the Tracking Map

+

View your live train position on the map while playing Train Sim World.

Step 1: Load a Timetable

  1. Go to the Tracking Map page
  2. In the "Load Timetable" section, select your Route
  3. Select the Train
  4. Select a Timetable (only timetables with recorded coordinates will appear)
  5. Click "Load Timetable"

Step 2: View Live Tracking

Once connected to Train Sim World:

  • Your train position appears as an orange marker
  • The route path is shown as a blue line
  • Station stops are marked with green circles
  • The info panel shows your current speed and direction

Step 3: Timetable Information

The timetable display shows:

  • Game Time: Current in-game time
  • Next Stop Time: Scheduled time for the next station
  • Distance: Distance remaining to the next stop

Step 4: Follow Mode

  1. Click "Follow Train" to keep the map centered on your position
  2. Click "Stop Following" to browse the map freely
Tip: Click "Open HUD" to open a dedicated heads-up display window that you can position alongside your game.
Map Legend:
- Blue line = Route path
- Green circles = Timetable stations
- Orange marker = Your live train position

Automated Data Collection (new_method.py)

+

Automatically capture all service data for a route using AI-powered screen reading. This bot uses the Claude API to navigate Train Sim World menus and extract timetable data without manual screenshots.

Prerequisites

  1. Anthropic API key set as environment variable (ANTHROPIC_API_KEY)
  2. TSW HUD server running (use run.bat --no-subscriptions)
  3. Train Sim World installed and configured

How It Works

The bot operates in 4 phases:

  1. Setup Phase: Launches TSW, navigates to the route selection screen, and selects the configured route
  2. Page Capture Phase: Scrolls through all service pages and captures screenshots of each one
  3. Service Discovery Phase: Uses Claude API to analyze captured pages and identify all service names and positions
  4. Service Processing Phase: Clicks each service, captures the timetable data, and uploads it to the HUD database

Commands

Run from the bot/ directory:

  • python new_method.py — Full run: launches game, captures all services
  • python new_method.py --no-launch — Skip game launch (game already running and on service screen)
  • python new_method.py "Train Name" 1 110 — Resume from a specific train, train number, and service number

Configuration

Before running, update ROUTE_NAME in bot/config.py to match your target route. Progress is saved automatically to progress_new_method.json, so the bot can resume if interrupted.

Important: Do not move the mouse or interact with the computer while the bot is running. It controls the mouse and keyboard to navigate game menus.
Tip: Use --no-launch when the game is already open to save time. The bot will start from the service selection screen.

Screen Calibration (calibrate.py)

+

Calibrate the bot's screen coordinates for your display resolution. This interactive 21-step tool captures reference images and measures pixel positions for all UI elements the bot needs to click.

When Is Calibration Needed?

  • First time setting up the bot on a new computer
  • After changing your display resolution or scaling
  • After a Train Sim World update that changes the UI layout
  • If the bot is clicking in wrong positions

Commands

Run from the bot/ directory:

  • python calibrate.py — Run all 21 calibration steps
  • python calibrate.py --step 5 — Run only step 5
  • python calibrate.py --from 10 — Start from step 10 onward
  • python calibrate.py --list — List all calibration steps

Calibration Steps

The tool guides you through capturing each game screen. Here are some of the key reference images it captures:

Main menu "To the Trains" button

Route selection screen

Timetable selection

Driver selection hover state

Get Started button hover state

In-game schedule screen

Route search bar position

Level loading splash screen

Service list click positions

Output Files

  • calibration.json — All measured coordinates and dimensions
  • 1_config.py — Generated Python config with calibrated values
  • references/*.png — Updated reference images for screen matching
Tip: If only specific elements are misaligned, use --step N to recalibrate just that step instead of running the full calibration.

Service Click Calibration (calibrate_service_scroll.py)

+

Test and fine-tune the click positions for each service in the service list. This tool verifies that the bot can correctly click on every service entry, and helps you adjust Y-position drift per page.

Prerequisites

  1. A services.csv file generated from a previous calibration or bot run
  2. Train Sim World running and on the service selection screen
  3. Screen calibration completed (calibrate.py)

Commands

Run from the bot/ directory:

  • python calibrate_service_scroll.py — Test all services from the beginning
  • python calibrate_service_scroll.py --from 130 — Start testing from service number 130
  • python calibrate_service_scroll.py --step 130 — Test only service number 130
  • python calibrate_service_scroll.py --restart — Reset and start from the beginning

How It Works

  1. The tool scrolls to each service's page in the game
  2. It clicks the service at the calculated Y-position
  3. It captures a screenshot and uses AI to verify the correct service was selected
  4. If wrong, use the global hotkeys to nudge the Y-position up or down
  5. At the end, it outputs suggested PAGE_Y_DRIFT values for config.py

Page Y Drift Correction

Different pages in the service list may have slight vertical offsets. The tool detects these and suggests per-page drift corrections that you add to PAGE_Y_DRIFT in bot/config.py. You can also run python evaluate_drift.py to automatically compare captured data against expected values.

Tip: During testing, use the global hotkeys to adjust click positions in real-time. The adjustments are saved and reported at the end as drift suggestions.

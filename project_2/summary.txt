Key binary format findings
UE4 FPropertyTag structure:

8 bytes FName (name) → 8 bytes FName (type) → int32 size → int32 arr_idx → type-specific extras → 1 byte has_guid [+ 16 byte guid]
BoolProperty: extra uint8 bool value BEFORE has_guid
StructProperty: extra FName (struct type) + 16-byte guid BEFORE has_guid
ArrayProperty: extra FName (inner type) BEFORE has_guid
Critical bug fixed: ArrayProperty<StructProperty> with count==0 has NO inner tag header — must skip immediately.

Service structure (RouteTimetableServiceDefinition):

Name (NameProperty) → e.g. NB_0535
FriendlyName (TextProperty) → e.g. "2U02 : Ryde St. Johns - Ryde Pier Head"
FormationName, MapPointA, MapPointB, bIsPlayerDrivable, Description, StartTime (Timespan)
Instructions (ArrayProperty of RouteTimetableServiceInstruction)
Instruction structure:

InstructionType (EnumProperty) → GoTo or LoadUnload
Destination (StructProperty RouteLocation) → contains Name (NameProperty) = station name e.g. "Ryde Esplanade Platform 1"
ArrivalTime, SimulatedArrivalTime, SimulatedCompletionTime (all Timespan = int64 ticks, 100ns each)
LoadingCriteria (ArrayProperty of RouteTimetableInstructionLoadCargoEntry) → bLoad, bUnload, MinimumTime
Schedule logic:

GoTo → LoadUnload pair = stop with passengers
arrival = LoadUnload.ArrivalTime (scheduled)
load time = arrival + MinimumTime (30s typically)
bLoad=True → LOAD PASSENGERS; bUnload=True → UNLOAD PASSENGERS
Bare GoTo (no following LoadUnload) = positioning move, no scheduled time (e.g. depot siding)
Times: Ticks ÷ 10,000,000 = seconds. Convert to HH:MM:SS.

Lat/lng NOT in timetable data — Destination has NetworkRibbonLocation (track GUID + float offset). Real coordinates need a separate route/network asset.

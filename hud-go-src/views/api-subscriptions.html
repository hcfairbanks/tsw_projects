TSW API Calls

The CommAPI paths the app subscribes to, organised into sections. Toggle calls on/off, add your own calls and sections, or create a new named section. Built-in sections ("Core", "German Safety") are specially parsed; calls you add to your own sections are streamed to HUDs under their key. Stored in resources/api_calls.json. Click "Save & Reapply" to apply (or changes apply on the next TSW reconnect).

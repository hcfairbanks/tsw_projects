Custom HUDs

Build your own HUD with an AI

Custom HUDs are standalone HTML pages in your resources/custom_huds folder. Add any TSW API call on the API Subscriptions page, then hand an AI the guide below together with a description of what you want to see — it can produce a single HTML page you drop into that folder, and it will appear here automatically.
